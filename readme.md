# CommandsToDo

A simple Todo List written in pure C.

>CommandsToDo is a small educational project created to understand how high-level programming language features work internally — especially dynamic arrays and string handling.

>The main goal of this project is not to create a feature-rich Todo application, but to recreate some basic functionality manually using low-level C features and memory management.

## Why?

Modern programming languages provide convenient structures like:

- Python `list`
- Java `ArrayList`
- C++ `std::vector`
- JavaScript `Array`

But behind these abstractions there are still simple concepts:

- allocated memory blocks
- pointers
- resizing strategies
- copying data

CommandsToDo is an attempt to understand these mechanisms by implementing them manually.

## Goals

The project was created to explore:

- How dynamic arrays work under the hood
- Manual memory allocation and reallocation
- String storage and manipulation in C
- Data structures without built-in containers
- How higher-level languages simplify common operations
